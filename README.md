# Friendship (友谊模组)

A relationship-growth mod for multiplayer Minecraft: bond with friends through
gifts, check your friendship level in the panel (default key `Z`), and revive
downed teammates once your friendship runs deep enough.

- **Minecraft:** 1.21.1
- **Loaders:** NeoForge (original also ships a Fabric build)
- **Original project:** https://modrinth.com/mod/friendship-breezeth
